# Website fonts

These fonts are served locally so readers do not need to access a font CDN.
CSS selects Fira Code for Latin text and Source Han Sans SC (思源黑体) for Chinese.

- `FiraCode-VF.woff2`: Fira Code 6.2, variable weight 300–700.
  Source: https://github.com/tonsky/FiraCode/releases/tag/6.2
  License: `FiraCode-LICENSE.txt` (SIL Open Font License 1.1).
- `SourceHanSansSC-VF.otf.woff2`: Adobe Source Han Sans SC, variable weight 250–900.
  Source: https://github.com/adobe-fonts/source-han-sans/blob/release/Variable/WOFF2/OTF/SourceHanSansSC-VF.otf.woff2
  Verified upstream Git blob SHA-1: `28045fc4cc3a2c66bd096573cec049e859879380`.
  License: `SourceHanSans-LICENSE.txt` (SIL Open Font License 1.1).

Retain both license files when distributing the website.
